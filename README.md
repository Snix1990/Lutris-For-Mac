# LutrisForMac

**macOS-native Game Library Manager** – SwiftUI + AppKit, inspired of [Lutris.net](https://lutris.net).


## Build and Start

```bash
git clone https://github.com/Snix1990/Lutris-For-Mac
cd Lutris-For-Mac
swift build
swift run LutrisForMac
```

for Xcode:

```bash
open Package.swift
```

> Release‑Build: `swift build -c release && swift run -c release`

## Systemrequirements

- **macOS 14+** (Sonoma), tested on MacOS 26.5
- **Apple Silicon** (M1+) , x86_64 not activly tested
- **Swift 6.0+**
